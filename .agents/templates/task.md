# 任务卡

复制后将说明替换为实际内容。尚未确定的内容写“待确认、由谁确认、何时反馈”。

| 字段 | 填写内容 |
| --- | --- |
| 做什么 | 谁在什么场景要得到什么结果；本次做到哪里 |
| 需求链接 | 最新需求或讨论结论的位置；暂无链接时直接写约定，之后补回 |
| 负责人输入 | 实现者；需求 / 体验确认者；需要谁提供什么材料与何时提供 |
| 正确例子 | 输入 / 操作 → 预期结果；涉及权限、截止等风险时补一个拒绝或失败例子 |
| 演示时间 | 本轮约定的演示日期或反馈点；调整后同步更新 |
| 进展 / PR | 提案 / 已定 / 待确认；已完成的可见结果、下一步、阻塞及 PR 链接 |
