# hackathon-regression

读取 `.agents/quality/RECURRENCE.md`。在现有 ledger 和真实改动里找证据，按根因而非措辞分组。优先结构消除错误路径，再类型/Schema，再有指导性诊断的 lint，再行为测试；需要判断的内容才增加简短指令。
证明新增检查对历史坏例失败、对修正版通过、对合理反例不误报。旧问题采用增量治理，豁免有责任人、理由、到期和复核。将执行入口与回归位置记回原 ledger，避免第二套问题账本。未经授权不改生产配置，不把“修规则”变成放宽标准。
