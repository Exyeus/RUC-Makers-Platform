# 香港站队伍与想法页面拆分

原来集中在“我的队伍”的内容拆为三个独立 URL，保留原有配色与组件样式：

| 页面 | 路由 | 内容 |
| --- | --- | --- |
| 我的队伍 | `teams/` | 自己的成员、招募资料、私密邀请码、队长交接、入队审批和退出操作 |
| 参与队伍 | `teams/discover/` | 其他招募队伍、主动公开找队伍的选手、邀请码加入、自己发出的申请及撤回 |
| 想法交流 | `ideas/` | 公开帖子、问题、想法、作品进展和自己的交流草稿 |

三个入口均在侧栏、选手手机底栏和页内导航中显示。首页和宣传页的找队友/赛道入口进入“参与队伍”；队伍管理返回“我的队伍”；帖子与 Idea 编辑归属“想法交流”。匹配推荐仍可从“参与队伍”进入。

“我的队伍”需要登录；未完善资料的登录用户有直接完善资料入口。“参与队伍”和“想法交流”沿用原活动范围与准入检查。目录排除自己的队伍及自己，不扩大其他选手的展示授权；私密邀请码仅在本队队长管理页显示。草稿查询仍限定作者，屏蔽与资料隐藏规则保留。所有变更操作沿用原服务、POST 和 CSRF 校验。

本轮无数据库迁移，也不改变开放测试、正式组队、隐私或 OSS 自动续期政策。原 `teams/` 保留为个人队伍管理；旧帖子详情及操作 URL 保留。

Git 分支 `refactor/hk-team-sections-20261115`；改动前标签 `backup/hk-team-sections-before-20261115`。部署与恢复交接位于本机工作区 `team-sections-hk-20261115/HANDOFF.md`；生产逐文件备份位于 `/srv/ruc-makers/ops/team-sections-20261115/`。生产恢复须检查后续源码变化，不使用整库恢复或 `git reset --hard`。
